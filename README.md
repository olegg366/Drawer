# MagicDraw 🎨

MagicDraw - это интерактивное приложение для рисования с помощью жестов и генерации изображений на основе голосовых команд.

Пользователь рисует в воздухе рисунок, при помощи камеры он считывается в линию на экране. Затем, когда его набросок готов, он вносит в систему голосовую подсказку к тому, что он нарисовал, а нейросеть догенерирует нарисованный контур до соответствия подсказке. То есть, если нарисовать круг, и сказать сова, она нарисует круглую сову.

## Возможности 🌟

- Рисование с помощью жестов рук
- Распознавание голосовых команд для генерации изображений
- Интерактивный интерфейс с настройкой толщины линий и цветов
- Поддержка сохранения сгенерированных изображений
- Интеграция с API для генерации изображений

## Технологии 🔧

- **Python 3.x**
- **TensorFlow/Keras** для распознавания жестов
- **MediaPipe** для отслеживания рук
- **Flask** для API сервера
- **Tkinter** для пользовательского интерфейса
- **OpenCV** для обработки изображений
- **NumPy** для работы с массивами данных

## Архитектура приложения 🏗️

Приложение состоит из двух независимых частей:

- **Клиент** (`src/commander.py`, `src/interface.py`, `src/gesture_recognizer.py` и др.) — распознаёт жесты рук, слушает голосовые команды и отрисовывает холст.
- **API-сервер генерации** (`src/api.py`) — принимает эскиз и текстовую подсказку, прогоняет их через Stable Diffusion + ControlNet и возвращает сгенерированное изображение. Для его работы нужна видеокарта с поддержкой CUDA, так как модель загружается на GPU (`.to('cuda')`).

Клиент обращается к серверу по URL, заданному в переменной `api_url` в `src/commander.py` (по умолчанию там прописан адрес девтуннеля вида `https://.../generator`). Есть два варианта, как это настроить.

## Установка 📦

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/username/MagicDraw.git
   cd MagicDraw
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## Запуск 🚀

### Вариант 1. Использовать готовый сервер

Если сервер генерации уже где-то запущен, локально поднимать `api.py` не нужно — достаточно подключиться к нему.

1. Укажите адрес готового сервера в `src/commander.py`:

   ```python
   api_url = 'https://<адрес-сервера>/generator'
   ```

2. Запустите клиент:

   ```bash
   python src/commander.py
   ```

### Вариант 2. Запустить сервер и обращаться к localhost

1. Убедитесь, что на машине есть GPU с поддержкой CUDA и установлен `torch` с CUDA-сборкой (см. `requirements.txt`).

2. Запустите сервер генерации. По умолчанию Flask поднимается на `127.0.0.1:5000`:

   ```bash
   python src/api.py
   ```

   При необходимости можно явно задать хост и порт, изменив последнюю строку `src/api.py`:

   ```python
   app.run(host='0.0.0.0', port=5000, debug=False)
   ```

3. В `src/commander.py` укажите адрес локального сервера:

   ```python
   api_url = 'http://127.0.0.1:5000/generator'
   ```

4. В отдельном терминале (не закрывая сервер) запустите клиент:

   ```bash
   python src/commander.py
   ```

> 💡 Быстро проверить, что сервер отвечает, можно с помощью `src/client.py` — тестового скрипта, который отправляет картинку и подсказку на `/generator` и показывает результат. Перед запуском поправьте в нём URL на `http://127.0.0.1:5000/generator`, если тестируете локальный сервер, либо оставьте адрес удалённого сервера для варианта 1.

## Управление жестами 👋

- 👍 **Большой палец вверх** - начать/закончить рисование
- ☝️ **Указательный палец вверх** - перемещать курсор
- 👆 **Жест "клик" (сжатые пальцы)** - рисовать
- ✋ **Открытая ладонь (две руки)** - очистить весь холст

## Требования к системе 💻

- Python 3.x
- Веб-камера
- Микрофон
- Достаточно оперативной памяти для работы с нейронными сетями
- Для локального запуска сервера генерации — видеокарта с поддержкой CUDA
